# Changelog

## 0.1.0

- Configure multiple isolated OpenCloud Agents.
- Manage persistent instructions, allow-listed models, KubeOpenCode Registry skills/plugins, and public custom Git skill repositories.
- Find and multi-select Registry skills and plugins in a responsive, searchable in-extension dialog.
- Keep dialogs visually distinct with a softly dimmed backdrop, a theme border, and a prominent, non-destructive red close icon; catalogue dialogs fill the entire webview while their result lists scroll independently.
- Give every button family a consistent, theme-aware hover state while preserving secondary, destructive, selected, and disabled semantics.
- Keep Agent creation, deletion, and unsaved-change confirmations inside the extension UI.
- Keep platform-required skills selected and immutable in the extension.
- Open the selected Agent through a static primary-blue terminal launcher with white iconography, accessible status feedback, and duplicate-launch protection.
- Preserve platform-managed environment and credentials outside the UI.
